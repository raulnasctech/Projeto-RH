# Project Overview: Sistema de Gestão de Recursos Humanos (RH)

## 1. Visão geral
Este projeto consiste no desenvolvimento de um sistema de Recursos Humanos concebido para centralizar e simplificar a gestão de colaboradores dentro de uma empresa. A aplicação funcionará como a principal ferramenta para a administração de pessoal e controlo de assiduidade.

## 2. Problema
Muitas empresas enfrentam dificuldades em centralizar as informações dos seus colaboradores e gerir eficientemente os horários e turnos. A utilização de processos manuais ou ferramentas dispersas gera desorganização, perda de tempo e possíveis erros no acompanhamento da assiduidade e gestão de equipas.

## 3. Objetivos
- Centralizar toda a informação referente aos colaboradores num único sistema.
- Facilitar e automatizar a gestão de horários e turnos de trabalho.
- Reduzir a carga administrativa da equipa de RH.
- Fornecer aos funcionários uma plataforma clara para acompanharem as suas próprias informações.

## 4. Público-alvo / utilizadores
O sistema destina-se a dois perfis principais:
- **Gestores/Equipa de RH:** Responsáveis por administrar os dados, criar horários e gerir as equipas.
- **Funcionários gerais:** Colaboradores da empresa que utilizarão o sistema para consultar os seus horários e as suas informações profissionais.

## 5. Principais funcionalidades
O escopo inicial do sistema deverá abranger:
- **Gestão de Colaboradores:** Registo e manutenção dos dados pessoais e profissionais dos funcionários.
- **Gestão de Horários:** Definição e alocação de turnos e horários de trabalho.
- **Controlo de Assiduidade:** (A definir - ex: registo de ponto, faltas e justificações).

## 6. Arquitetura tecnológica
- **Frontend:** Reflex.
- O Reflex será utilizado como tecnologia exclusiva para a implementação do frontend da aplicação.

## 7. Estratégia de desenvolvimento
O projeto será desenvolvido de forma incremental utilizando o OpenSpec. As mudanças serão especificadas e revistas antes da implementação de qualquer código.
