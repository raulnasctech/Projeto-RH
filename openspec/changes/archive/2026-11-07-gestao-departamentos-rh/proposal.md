# Proposal: Gestão de Departamentos

## Why

Atualmente, os departamentos da empresa existem na base de dados, mas não há uma interface dedicada para que o Gestor de RH possa gerenciar (cadastrar, listar e editar) os departamentos diretamente na aplicação.

## What

- Criar endpoints no Xano para listagem, cadastro e edição de departamentos na API `rh_api`.
- Criar a tela de Gestão de Departamentos no Reflex para o Gestor de RH.
- Atualizar a barra lateral para incluir o acesso a Departamentos.
